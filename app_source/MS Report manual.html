MS Report Manual

Turns a folder of LC-MS .raw files into editable PowerPoint slides (structure, HPLC, calculated vs observed m/z, MS spectrum, TIC), one slide per peptide, and looks for what else is in each sample.

1. Quick start

Install the app (once)

  1. Unzip MS Report for Mac.zip and drag MS Report into Applications.
  2. Double-click it. If macOS says it cannot verify the app, click Done, open System Settings › Privacy & Security, scroll down and click Open Anyway.
  3. Click Install and wait 2-5 minutes (internet and about 600 MB of disk space; no administrator password).
  4. If macOS asks whether MS Report may use your Downloads, Documents or Desktop folder, click Allow.

Each experiment

  1. Put the .raw files, a water/blank run (name containing H2O or blank) and the peptide list in one folder. The list is either the batch synthesis Excel sheet (3-letter codes, one per cell, numbered rows) or a .csv with one-letter sequences.
  2. Open MS Report and click Choose folder (or a recent folder).
  3. For a new folder, click Read sequences and match raw files. The Samples tab then lists every peptide.
  4. Check the table: Topology for every row, the Raw file and the Blank. Rows with a problem have a red edge and say what is wrong; Needs fixing shows only those. Click Save.
  5. In the Run tab click Make report. When it is ready, click Open slides, or look through the Results tab.
Everything is written to MS_report inside the data folder. The table is the file samples.csv in the data folder; Open in Excel opens it there, and the window reloads it when you come back.

Working with many samples

  • Change many rows at once: tick the rows (shift-click ticks a range, the box in the header ticks every row shown), then use the blue bar: Topology, Blank, Role, Find deltas, or Delete rows.
  • Paste a column from Excel: copy the cells, click the first cell to fill (e.g. Sequence of row 1) and paste. The lines fill the rows below; rows are added if needed. Tab-separated columns fill the next columns.
  • Move around: arrow up/down or Return go to the same column in the next row; ⌘S saves.
  • Filter: the search box matches id, name, sequence and file; the chips show only rows that need fixing, rows without a raw file, or blanks.
  • Run only some samples: tick them in Samples, then choose Only the rows selected in Run. That report then has only those slides.
  • Under each sequence: residues, formula, monoisotopic mass, the first ions ([M+2H]2+, ...) and how many deltas will be searched, updated as you type.

4. find_deltas: what else to look for

Besides the expected peptide, the report searches each sample for related species: impurities, adducts and leftovers. Write one or more of the words below, separated by a comma and a space.

WriteSearches for
auto (default)linear, adducts, side_reactions, protecting_groups, deletions, insertions and dimer, keeping only the deltas that fit the residues of this peptide (e.g. Pbf only if it has an Arg).
allEvery delta in building_blocks.csv, whatever the sequence. Most thorough, most chance hits.
noneOnly the expected peptide.
linearThe uncyclised precursor of a head-to-tail peptide (+H2O).
deletionsEach residue of the sequence missing once (incomplete coupling).
insertionsEach residue present twice (double coupling).
dimer2M (odd charge states only; even ones sit on top of the monomer).
adductsNa+, K+, NH4+.
side_reactionsOxidation, deamidation, water/ammonia loss, aspartimide-piperidide, formyl, methyl/ethyl ester, Tfa, TMG cap from HBTU/HATU, sulfonation, EDT and HMP adducts, ...
protecting_groupstBu, Boc, Trt, Pbf, Pmc, Mtt, Mmt, Fmoc, Acm, StBu, Bzl, Alloc, ivDde, Dmb, Hmb left on.
a code, e.g. +Pbf, +NaJust that one delta.
a group you madeEvery row of building_blocks.csv with that group (section 5).

Examples: auto · linear, adducts · deletions, +Pbf, +tBu · all. To see every delta with its exact mass, run python3 make_ms_report.py deltas in Terminal.

Chance hits. The more deltas you search, the more will match something by chance. Each run is therefore also searched with another peptide's sequence, and the report prints both counts, e.g. "12 delta hits with the right sequences, 7 with another peptide's sequence". Treat delta hits as leads to check, not proof. Only confident hits ("yes") go on the slide; weak ones are listed in data/<id>_mz_table.csv.

The deltas come from the Novabiochem peptide delta-mass sheet, written as exact formulas.

5. building_blocks.csv: adding monomers, tags and deltas

All masses come from this file. The app keeps it in Documents/MS Report/building_blocks.csv; a copy in the data folder takes priority for that folder only. Every time it starts, the script checks that each row's structure and formula agree, and refuses rows that don't.

ColumnMeaning
codeWhat you write in a sequence or in find_deltas. One letter for canonical residues; anything else for the rest (Aib, Biotin, +Pbf).
code33-letter code, used to read Excel sheets and for the 3-letter sequence on the slide.
nameDescription.
kindresidue, n_cap, c_cap, tag, adduct (a charge carrier like Na) or shift (a mass change).
formulaWhat the unit adds to the peptide. Residue = amino acid minus H2O (C3H5NO for Ala). Tag = group added minus the H it replaces. Shift = net change, which may be a loss (-H2O) or a gain minus a loss (C5H9N-O).
smilesStructure with attachment points: [*:1] N side, [*:2] C side, [*:3] side chain (for tags). Required for residues, caps and tags; not used for deltas.
groupDeltas only: which find_deltas group the row belongs to. Use one of the existing groups or invent one (lower case, e.g. my_linkers), then write that name in find_deltas.
residuesDeltas only: one-letter codes the delta can happen on (e.g. R for Pbf). auto skips the row when the peptide has none of them. Blank means it applies to any peptide.
notesFree text.

6. Reading the report

PanelShows
AStructure, formula and exact mass. The drawing is a starting point; open data/<id>.mol in ChemDraw to tidy it.
BHPLC trace. Without an HPLC file: a zoom on the product's strongest charge state, each isotope peak labelled with its measured m/z (monoisotopic in red). If the product is not found, the zoom shows where it would be; a nearby peak outside 5 ppm is labelled in orange with its error, because it is something else.
CCalculated vs observed m/z, the error in ppm and the retention time, for the expected peptide and every confident delta hit. Side products often elute at another time than the product. n.d. = not detected.
DMS spectrum averaged over the product's elution peak (minus the blank when there is one), full scan range. Red labels: expected ions and confident delta hits; green: other major peaks.
ETotal ion chromatogram, the blank in grey. Red line: where the product elutes (labelled cyclic 4.53). Grey line: the product was not found and D shows the largest TIC peak. Labelled set by user when spectrum_rt is filled.

All charts are native PowerPoint charts: right-click › Edit Data, or click a label to move or delete it. Labels never overlap; a label that would not fit is left out (the slide says so for expected ions).

When is something "found"?

An ion counts when its monoisotopic peak, its first 13C peak (at the ratio the formula predicts) and, for larger peptides, the second 13C peak are within 5 ppm, in at least 8 consecutive scans, at 1% of the base peak or more. In summary.csv, yes means 2 or more charge states, or one at 5% of the base peak or more. weak means one charge state below 5%; unrelated peptides reach this level by chance, so it is not proof.

Output files (MS_report folder)

MS_report.pptxThe slides; the notes under each slide list the details.
summary.csvOne line per sample: found or not, retention time, ppm, delta hits (with the chance level), main peaks.
data/<id>_mz_table.csvTable C including weak hits.
data/<id>_main_peaks.csvThe biggest LC peaks: mass, difference from the expected mass, possible explanations, and whether it is also in the blank.
data/<id>_spectrum.csv, _tic.csv, _blank_tic.csv, _hplc.csv, _isotope_zoom.csvThe numbers behind each chart (ready for Prism). The spectrum file has the blank and the subtracted values; the zoom file has the calculated isotope pattern too.

7. Terminal use (Carlos)

cd "<data folder>"            # with make_ms_report.py copied into it
python3 make_ms_report.py        # setup the first time, then the report
python3 make_ms_report.py help   # full list of commands and options

python3 ~/Downloads/MSdata/Script/dashboard.py --browser   # the MS Report window, in the web browser
CommandDoes
setupRewrite samples.csv from the .xlsx/.csv (the old one is kept as samples_old.csv).
checkCheck samples.csv and print the calculated m/z; no MS data read.
runMake the report. Options: --only 1,5, --ppm 5, --max-charge 6, --min-rel 1, --min-scans 8.
mass "SEQ"Quick m/z calculator (--topology head-to-tail).
blocks / deltasList the building blocks / what find_deltas can search for.

The window and Terminal run the same script, so they give the same report. After changing make_ms_report.py, dashboard.py, dashboard.html or building_blocks.csv in the Script folder, rebuild the app and zip with bash ~/Downloads/MSdata/Script/app_source/build_app.sh.

MessageWhat to do

raw_file ... not foundThe name in samples.csv does not match a file in the folder.
Problems in building_blocks.csvThe message names the line and the reason (e.g. structure and formula disagree).
No raw files (new folder)Choose the folder that holds the .raw files.

The window does not openOpen MS Report again. If it still fails, send Carlos the file Documents/MS Report/dashboard.log.
